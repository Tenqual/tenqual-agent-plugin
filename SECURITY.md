# Security

Report suspected vulnerabilities privately to security@tenqual.com. Do not open a public issue containing credentials, customer data, or exploit details.

The plugin package contains no secret. Tenqual's hosted service enforces Firebase sign-in, workspace membership, OAuth scopes, API-key scopes, quotas, and revocation. Access can be revoked from the Tenqual Integrations page.

Never commit OAuth tokens, API keys, reviewer credentials, signed document URLs, or production response payloads to this repository.
